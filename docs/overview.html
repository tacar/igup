IGUPとは

IGUPは、Instagramのキーワード自動返信・予約投稿・分析・LINEセミナー集客までを、このPCだけで完結させるデスクトップアプリです。クラウドの月額サービスにデータを預けるのではなく、自動化の判断も実行もすべて手元のPC上で行います。

PCで動く「IGUPデスクトップ」が本体で、投稿・DM送信・分析取得はここからInstagram / Threads / LINEへ直接行います。もうひとつの部品「ブローカー」は、公開ホストに立てる薄い窓口で、OAuthの中継とWebhookの取り次ぎ、画像の一時公開、計測リンクとセミナー申込ページの公開だけを担当します。

  • 自分のアカウントを、自分で接続する。Instagram・Threadsとも、本人がログインして許可を出すOAuth方式です。パスワードをIGUPに渡す必要はありません。
  • 秘密情報はPCの中だけ。接続後のアクセストークンや、LINE・ローカルAPIのトークンは、OSの暗号化機能でこのPC内にだけ保存されます。
  • ブローカーは中身を持たない窓口。Meta / ThreadsのApp Secretは環境変数として起動時に渡すだけで、ファイルにもコードにも書きません。動画はPCから直接Instagramへアップロードされ、ブローカーを経由しません。

できること

自動返信からLINEセミナー集客まで、Instagram運用に必要な機能をひとつのアプリにまとめています。

自動返信とメッセージ

01

キーワード自動返信

コメント・DM・ストーリーズ返信・ライブ配信コメントに反応し、公開返信（3パターンまでランダム）とDMを自動送信します。

02

リンク付きボタン

DMにWebサイトへのボタンや、別の自動返信につながる選択式ボタン（最大3つ）・クイックリプライ（最大13個）を添付できます。

03

メッセージ連鎖

ボタンやクイックリプライのタップをきっかけに、別のルールのDMを続けて送る会話の分岐を作れます。

04

時間差送信

最初のDMの後、指定した時間（1分〜23時間）が経ってから追加のメッセージを自動送信します。

予約投稿とコンテンツ

05

予約投稿

フィード画像・カルーセル（2〜10枚）・リール（表紙画像つき）・ストーリーズを日時指定で自動投稿します。投稿後、そのメディアに自動返信ルールを紐づけられます。

06

Threads予約投稿

複数の投稿をツリーとして連結したり、最大20枚のカルーセルを予約投稿できます。

07

カレンダー管理

予約投稿とメモを月表示で確認できます。メモは色分けして予定を整理できます。

08

画像アップロード＆切り抜き

ドラッグ＆ドロップでPC内の画像を取り込み、投稿種別ごとの比率でクロップ・並び替えできます。PNGは自動でJPEGに変換します。

分析と計測

09

タップ分析

DMのボタン・クイックリプライについて、届いた数・見られた数・押された数を記録します。

10

計測リンク

短縮リンクを発行し、クリック数を媒体別・日別・ランキングで確認できます。プレビュー用のクローラーアクセスは集計から除きます。

11

投稿インサイト

投稿ごとの反応をTop10表示し、フォロワー・リーチの推移をグラフで確認できます。24時間で消えるストーリーズの数値も、消える前に保存します。

集客と運用

12

LINEセミナー連携

申込ページを公開し、申込者へLINEでお礼とリマインド（複数回設定可）を自動送信します。日程は複数設定でき、申込ページのQRコードも発行します。

13

ライブ配信コメントへの自動DM

ライブ配信中のコメントにも、通常のコメントと同じルールで自動返信できます。

14

送受信ログ

受信・送信・投稿・分析・セミナー・リンクの記録を、カテゴリごとに確認できます。

15

画面カラー変更

テーマ（ライト／ダーク／OSに合わせる）とアクセントカラーを自由に変更できます。

16

ローカルAPI

Claude CodeなどのAIツールから、画面を使わずに投稿予約やルール作成、分析取得を行えるHTTP APIです（既定は無効）。詳しくはAIツール連携を参照してください。

設計の方針

自動返信や予約投稿の判断・実行はすべてこのPC上で行われます。ブローカーはOAuthの中継とWebhookの取り次ぎ、画像の一時公開だけを担当する薄い窓口で、動画を保存することはありません。各画面の詳しい操作方法は取扱説明書を参照してください。

仕組み

IGUPは「あなたのPCで動くデスクトップアプリ」と「公開ホストで動くブローカー」の2つで構成されます。Meta / ThreadsのApp Secretを持つのはブローカーだけで、アプリ本体には含めません。図は、接続後にデータがどう流れるかを示しています。

  1. 接続する。Instagram（必要ならThreadsとLINEも）を「接続」画面から接続します。認可はブラウザで行い、結果はブローカーを一度だけ経由してこのPCに渡ります。
  2. ルールと投稿を用意する。自動返信ルールや予約投稿を、画面またはローカルAPIから作成します。
  3. PCが自動で動く。Webhookまたは定期確認でコメント・DMを検知し、ルールに従って公開返信・DMを送信します。予約時刻が来た投稿はPCから直接Instagram / Threadsへ公開します。
  4. 結果を確認する。タップ分析・計測リンク・投稿インサイトが自動で記録され、送受信ログとあわせて画面で確認できます。

データの置き場所

場所置かれるもの残る期間
あなたのPC アクセストークン・LINEチャネルトークン・ローカルAPIトークン（すべて暗号化）、自動返信ルール・予約投稿・メモ・分析データ アプリを使い続ける間、このPCにだけ残ります。
ブローカー App Secret（起動時の環境変数）、認証の途中結果、Webhookイベント、一時公開した画像、計測リンクとセミナー申込の記録 認証の途中結果は最大5分。画像とイベントは既定24時間で自動削除。リンクと申込の記録は機能を使う間保持されます（アクセストークンは含みません）。

LINE 送信したお礼・リマインドメッセージ LINE上のトーク履歴として残ります。IGUP側にはチャネルトークン以外何も送りません。

安全性の設計

  • App Secretを配布しない。Meta / ThreadsのApp Secretはブローカー起動時の環境変数として渡すだけで、アプリ本体にもファイルにも含めません。
  • トークンはOSの暗号化機能で守る。アクセストークン、LINEチャネルトークン、ローカルAPIのトークンは、いずれもElectronの`safeStorage`（macOSはキーチェーン、WindowsはDPAPIを利用）でこのPC内に暗号化保存します。
  • ブローカーはトークンを持たない。OAuthの交換結果は最大5分だけメモリに置かれ、アプリが一度きりのコードで受け取った後は破棄されます。以降ブローカーが関わるのはWebhookの取り次ぎと画像の一時公開だけです。
  • 動画はPCから直接。動画はこのPCからInstagramの再開可能アップロードで直接送られ、ブローカーには保存されません。画像は一時公開されますが既定24時間で自動削除されます。
  • ローカルAPIは外に出ない。AIツール向けのローカルAPIは既定で無効、有効にしても`127.0.0.1`にのみバインドし、Bearerトークン（暗号化保存・タイミング攻撃対策済みの比較）を持つプロセスからしかアクセスできません。
  • 画面とOSを切り離す。アプリの画面部分はOSやネットワークに直接触れられない構成（contextIsolation・sandbox有効、nodeIntegration無効）です。
  • ブローカーも最小限。セキュリティヘッダー（helmet）を付与し、CORSはアプリの戻り先オリジンにのみ許可しています。
  • 2段階認証について。IGUPはこのPCでだけ動くアプリで、独自のログインIDやパスワードを持ちません。2段階認証はInstagram / Threads / LINEそれぞれのサービス側の設定がそのまま適用されます。

AIツール連携

「設定」画面でローカルAPIを有効にすると、Claude CodeなどのAIツールが画面を操作せずに投稿予約・自動返信ルール作成・分析取得などを行えるようになります。既定では無効です。

サーバーは127.0.0.1（このPCの中だけ）にバインドされ、外部ネットワークからは到達できません。有効化すると自動生成されるトークンをBearer認証に使います。

  • GET /status
  • GET/POST /rules
  • GET/POST /posts
  • POST /posts/:id/publish
  • GET /insights
  • GET/POST /links
  • GET/POST /seminars
  • GET /logs
  • GET /export

全エンドポイントの一覧とパラメータ、実行例はdocs/ai-integration.mdを参照してください。

必要なもの

あなたが用意するもの

  • Instagramプロアカウント（ビジネスまたはクリエイター）。個人アカウントはInstagram側で先に切り替えます。
  • Meta開発者アカウントとMetaアプリ。Instagram API with Instagram Loginを有効化します。
  • ブローカーを動かす公開HTTPSホスト。OAuthコールバックとWebhookの受け口になります。
  • （任意）Threadsアプリの設定。Threads予約投稿を使う場合。
  • （任意）LINE公式アカウントとMessaging APIチャネル。セミナー連携を使う場合。

アプリが用意しているもの

  • Electron製デスクトップアプリ（apps/desktop）。自動化・スケジューリング・分析・ローカルAPIをすべて内蔵しています。
  • 薄い中継サーバー（apps/broker）。OAuth中継・Webhook取り次ぎ・画像の一時公開・計測リンク・セミナー申込ページを担当します。
  • OSの暗号化機能を使った保存処理。トークン類は自動的に暗号化してPCに保存します。
