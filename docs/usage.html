このページはIGUPデスクトップアプリの画面ごとの使い方をまとめた取扱説明書です。左のメニュー、または上のジャンプリンクから、確認したい画面を選んでください。導入手順（Metaアプリの作成・ブローカーの起動など）はREADMEを、AIツールからの操作はdocs/ai-integration.mdを参照してください。

ご利用前に

  • Instagramプロアカウント（ビジネスまたはクリエイター）が必要です。個人アカウントの場合は、Instagram側で先に切り替えてください。
  • ブローカーの起動。接続画面を使うには、README の手順でMetaアプリを作成し、ブローカー（apps/broker）をあらかじめ起動しておく必要があります。
  • （任意）Threads・LINEの設定。Threads予約投稿にはブローカー側にThreadsアプリの設定が、LINEセミナー連携にはLINE公式アカウントのチャネルアクセストークンが必要です。どちらも未設定のままでも、Instagram機能だけで利用を始められます。

画面ガイド

01

Screen 1 / 9

ダッシュボード

「いまの状態と、これから起きることをひと目で。」がこの画面の役割です。Instagram・Threads・LINE・ブローカーの接続状態、直近の予約投稿、最近の自動返信・投稿の動きをまとめて確認できます。

いま確認する を押すと、次のポーリング（定期確認）を待たずにコメント・DMの確認と予約投稿の実行をその場で1回実行します。実行すると「確認を実行しました。」と表示されます。

ポーリングとWebhook

Webhookを登録していない場合、コメント・DMの検知は設定した間隔（既定は「設定」画面のポーリング間隔）ごとの定期確認になります。ダッシュボードのボタンは、この間隔を待たずにすぐ確認したいときに使います。

接続

Instagram・Threads・LINE・ブローカーの4枚のカードで接続状況を管理します。秘密情報はこのPCの安全な保管領域にだけ保存されます。

稼働中 ブローカーに到達できている
未接続 / 接続不可 接続または設定が必要
接続済み 利用可能

Instagram：Instagramに接続を押すと既定のブラウザでMetaの認可画面が開き、「ブラウザでInstagram認証を続けてください。」と表示されます。許可するとIGUPに戻り、以後はボタンが再接続するに変わります。

Threads：ブローカーにThreadsアプリの設定（THREADS_APP_ID など）がある場合のみ、Instagramとは別に接続できます。未設定の場合はボタンが無効になり、「ブローカーにThreadsアプリの設定（THREADS_APP_ID など）がないため利用できません。」と表示されます。

LINE：LINE公式アカウントのチャネルアクセストークンを貼り付けて保存します。空欄のまま保存するとLINE設定を削除できます。

複数アカウント：Instagramアカウントは複数接続できます。Instagramに接続で認証済みのアカウントとは別に「別のInstagramアカウントを追加」から追加すると、サイドバー上部のセレクタで切り替えられるようになります。予約投稿・自動返信ルール・分析はアカウントごとに作成・表示され、アカウントの接続期限が近づくと「再接続」で更新します。Threadsは選択中のアカウントに紐付いて接続されます。予約中の投稿があるアカウントは削除できません。

ブローカー：稼働中／接続不可のバッジと、Webhook・画像の一時公開・計測リンク・セミナー申込・Threads認証など、いま使える機能のバッジが並びます。接続できない場合は次のように表示されます。

ブローカーに接続できません。

README の手順で META_APP_ID / META_APP_SECRET / META_REDIRECT_URI を設定して npm run dev:broker を起動するか、IGUP_BROKER_URL に公開URLを設定してください。

セキュリティについて

アクセストークンとLINEチャネルトークンは、いずれもOS標準の暗号化機能でこのPC内だけに保存されます。ブローカーはApp Secretを持ちますが、あなたのアクセストークンを保存することはありません。

Screen 3 / 9

予約投稿

フィード・カルーセル・リール・ストーリーズ・Threadsを予約して自動投稿します。＋ 投稿を予約 から新規作成します。

投稿種別を選ぶと、必要な画像・動画の枚数が変わります。画像はドラッグ＆ドロップで取り込み、投稿種別ごとの比率（1:1 / 4:5 / 1.91:1 / 9:16 / 自由）でその場で切り抜けます。PNGは自動でJPEGに変換されます。リールには表紙画像を別途設定できます。

予約後、そのメディアに自動返信ルールを1つ紐づけられます。紐づけると、投稿へのコメントにそのルールが自動で反応するようになります。カルーセルは2〜10枚、Threadsのカルーセルは最大20枚、Threadsはツリー状に複数投稿を連結できます。

投稿を削除するときは確認ダイアログが出ます（「この投稿を削除しますか？」）。入力に問題があると、たとえば次のように表示されます。

  • 投稿日時を指定してください。
  • フィード画像投稿は画像1枚を選んでください。
  • カルーセルは2〜10枚の画像・動画を選んでください。
  • リールは動画1本を選んでください。

繰り返し予約

エディタで「繰り返し」をオンにすると、「毎日」「毎週（曜日を複数選択）」「毎月（日を指定）」に間隔・時刻・終了日を組み合わせた定期スケジュールを1件の設定にできます。投稿が公開される（または失敗する）たびに次の予定が自動で作られるため、あらかじめ組んだ曜日運用が続きます。リストでは「毎週月・木 20:00」のようなチップで表示され、削除は「この投稿を削除」か「シリーズごと削除」から選べます。

CSV一括読み込み

CSV読み込み（予約投稿とカレンダー画面にあります）で、予約投稿をまとめて登録できます。1行が「投稿日時・種別・キャプション・メディアパス・繰り返し・アカウント」に対応し、日本語ヘッダーと英語ヘッダーの両方を読めます。読み込む前にプレビュー表が表示され、日時やメディアに問題がある行は行番号つきで示されて読み込み時にスキップされます（問題のない行だけ登録）。文字コードはUTF-8（BOMあり推奨）のほかShift_JISも自動判別し、メディアパスはCSVファイルからの相対パスでも書けます。「サンプルCSVを書き出す」で書式見本を入手できます。

AIで文案を作成（任意）

「設定」でAI APIキーを保存すると、キャプション入力欄の横に ✨ AIで文案を作成 が表示されます。商品の概要・トーン・想定読者を入れて生成すると、キャプション案が3つとハッシュタグが提案され、ボタン1つで入力欄に挿入できます。AIに送るのは入力した概要と商品種別だけで、APIキーはこのPCの暗号化領域にだけ保存されます。設定しなくても他の機能はすべて使えます。

カレンダー

予約投稿とメモを月ごとに確認します。日付をクリックすると詳細と追加ができます。

投稿は種別ごとに色分けされたチップで表示されます（画像・カルーセル・リール・ストーリーズ・Threadsでそれぞれ異なる色）。公開済みの投稿は薄く表示され、失敗・実行漏れの投稿には取り消し線が付きます。

メモは7色から選んで色分けでき、投稿とは別に左端の色帯付きチップとして表示されます。前月・今日・次月ボタンで月を移動できます。

Screen 5 / 9

自動返信ルール

コメント・DM・ストーリーズ返信・ライブのキーワードに、公開返信とリンク付きDMを自動で返します。＋ ルールを作成 から新規作成します。

反応する入口（コメント／DM／ストーリーズ返信／ライブ配信コメント）とキーワード、一致方法（部分一致／完全一致）を設定します。コメント・ライブ配信は特定の投稿だけに絞ることもできます。

公開返信は最大3パターンまで登録でき、そのうち1つがランダムに選ばれて返信されます。DM本文（最大1,000文字）には、リンク付きボタン（最大3つ）やクイックリプライ（最大13個）を添付できます。ボタン・クイックリプライをタップさせて、別のルールのDMに続けて送る「メッセージ連鎖」も設定できます。

最初のDMのあとに、1分〜23時間の間隔で追加のメッセージを送る「時間差送信」も設定できます（Instagramの24時間ルールにより23時間が上限です）。同じ相手への再送を抑える「クールダウン」時間も設定できます。

入力チェックの例

  • ルール名を入力してください。
  • 反応する入口（コメント / DM / ストーリーズ返信 / ライブ）を1つ以上選んでください。
  • キーワードを1つ以上入力してください。
  • 公開返信は3パターンまでです。／ボタンは3つまでです。／クイックリプライは13個までです。
  • DM本文は1,000文字以内にしてください。
  • 時間差送信は23時間以内に設定してください（Instagramの24時間ルール）。

ルールを削除するときは「ルール『（ルール名）』を削除しますか？」という確認ダイアログが出ます。

分析

投稿インサイト・計測リンク・タップ分析をまとめて確認します。数字はこのPCに保存され、ストーリーズが消えたあとも残ります。

投稿インサイト：反応の良かった投稿をTop10で表示し、フォロワー数・リーチの推移を折れ線グラフで確認できます。ストーリーズは公開から24時間で消えますが、消える前に取得した数値をスナップショットとして保存します。

タップ分析：DMのボタン・クイックリプライごとに、届いた数・見られた数・押された数を記録します。

計測リンク：短縮リンクを発行し、投稿・プロフィールなど貼った場所ごとにクリック数を記録します。日別の推移やランキングで確認できます。作成すると「作成しました: （リンクURL）」と表示されます。プレビュー用のクローラーアクセスは集計に含みません。

計測リンクを削除するときは「この計測リンクを削除しますか？貼った先からはアクセスできなくなります。」という確認が出ます。削除すると、そのリンクを踏んでも先のURLに転送されなくなる点に注意してください。

Screen 7 / 9

セミナー

申込ページを公開し、申込があったらLINEでお礼を送り、開始前にリマインドします。

タイトル・説明・日程（開催日時と定員、最大30件）・お礼メッセージ・リマインド（何時間前に送るか、複数設定可）を設定します。お礼・リマインドの本文には {name} {title} {date} と書くと、申込者の名前・セミナー名・日時に自動で置き換わります。

LIFF ID（LINE Developersで作成）を設定すると、申込ページがLINE内で開き、申込者のLINEに自動でお礼・リマインドを送れます。空欄の場合はメールでの申込のみになります。

保存すると申込ページの公開URLが発行され、コピー・ブラウザで開く・QRコード表示ができます。申込一覧では、日程・名前・メール・LINE・申込日時・お礼とリマインドの送信状況を確認できます。

LINE公式アカウントが未設定です。

接続画面でチャネルアクセストークンを設定すると、お礼・リマインドを自動送信できます。

ブローカーに公開URL（PUBLIC_BASE_URL）が設定されていないため、申込ページを公開できません。

ブローカーの環境変数 PUBLIC_BASE_URL に、ブローカーの公開HTTPSアドレスを設定してください（未設定でも到達可能なら自動判定されます）。

送受信ログ

受信したコメント・DM、送った返信、投稿、分析の記録です（最新300件）。カテゴリタブ（すべて／受信／送信／投稿／分析／セミナー／リンク／システム）で絞り込めます。

各行には時刻・カテゴリ・タイトル・詳細が表示されます。「すべて削除」で確認ダイアログのうえログを一括消去できます。

設定

動作の細かい調整を行います。変更は すべて保存 で反映されます。

テーマ（ライト／ダーク／OSに合わせる）とアクセントカラー（8色のスウォッチまたはカスタム指定）、ポーリング間隔・ブローカーからのイベント確認間隔・直近メディア件数・実行漏れとみなす猶予時間・ストーリーズのスナップショット間隔などの自動化タイミング、ライブ配信コメント対応や分析取得のON/OFF、既定のキャプションを設定できます。

AI文章生成（任意）

プロバイダー（OpenAI互換 / Anthropic）・モデル・ベースURL・APIキーを保存すると、予約投稿エディタでキャプション案とハッシュタグの生成が使えるようになります。「接続テスト」で設定を確認でき、「キーを削除」で保存したキーを消せます。キーはOSの暗号化機能でこのPC内にだけ保存され、バックアップの書き出しには含まれません。設定しなくてもIGUPの他の機能はすべて使えます。

ローカルAPI（AI・外部ツール連携）

「ローカルAPIを有効にする」をONにすると、Claude CodeなどのAIツールから画面を使わずに投稿予約・ルール作成・分析取得ができるようになります。このPCの中だけ（127.0.0.1）で使えるHTTP APIで、トークンを知っているプロセスだけがアクセスできます。トークンは「表示」「コピー」で確認でき、「再生成」すると古いトークンは使えなくなります。使い方はdocs/ai-integration.mdを参照してください。

curl -H "Authorization: Bearer <トークン>" http://127.0.0.1:42814/status

バックアップ：ルール・投稿・メモなどの設定データを、秘密情報を含まない形でエクスポート・インポートできます。読み込み時は「現在のデータをバックアップの内容で置き換えます。よろしいですか？」と確認されます。

プライバシー・アプリ情報：Metaアプリ審査で求められるプライバシーポリシーに記載する問い合わせ先を設定できるほか、バージョン・データ保存先・メディア保存先・ブローカーURLを確認できます。

困ったときは

ブローカーに接続できません。

README の手順で META_APP_ID / META_APP_SECRET / META_REDIRECT_URI を設定して npm run dev:broker を起動するか、IGUP_BROKER_URL に公開URLを設定してください。

ブローカーにThreadsアプリの設定（THREADS_APP_ID など）がないため利用できません。

Threads予約投稿を使う場合は、ブローカーの環境変数に THREADS_APP_ID / THREADS_APP_SECRET を設定してください（任意機能です）。

Webhookが届かず、コメント・DMの反応が遅い。

Metaアプリのダッシュボードで Instagram > Webhooks にブローカーの /webhooks/instagram を登録し、検証トークン（META_WEBHOOK_VERIFY_TOKEN）を一致させてください。未登録でも「設定」画面のポーリング間隔ごとに定期確認されます。

投稿・ルールの保存時に入力チェックのメッセージが出る。

キャプションの文字数超過、画像・動画の枚数不一致、日時未指定など、投稿種別やDM内容ごとの条件を満たしていない可能性があります。メッセージに従って入力内容を修正してください。

LINEのお礼・リマインドが届かない。

「接続」画面でLINEチャネルアクセストークンが設定されているか、セミナーのLIFF IDが正しいか、申込者がLINEで申し込んでいるか（メール申込にはLINE送信できません）を確認してください。

ローカルAPIにアクセスできない／401が返る。

「設定」画面でローカルAPIが有効になっているか、リクエストのAuthorizationヘッダーのトークンが画面に表示されているものと一致しているかを確認してください。トークンを再生成した場合は、呼び出し側の設定も更新してください。
