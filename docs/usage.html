Operation Guide

IGUP

Instagramへの接続と画像投稿を、あなたのPCから。

Desktop App v0.1.0 3 Steps
01 接続 02 確認 03 投稿 困ったときは 仕様

IGUPは、InstagramプロアカウントのOAuth接続・アカウント情報取得・画像のテスト投稿を行う買い切り型のデスクトップツールです。Metaアプリのシークレットは認証サーバー側だけが保持し、あなたのPCへ配布されることはありません。

ご利用前に

  • Instagramプロアカウント（ビジネスまたはクリエイター）が必要です。個人アカウントの場合は、Instagram側で先に切り替えてください。
  • インターネット接続が必要です。IGUPはMeta社のInstagram APIと通信します。
  • 投稿する画像の公開HTTPS URLを用意してください。Instagram側から直接取得できる画像URLのみ対応しており、お使いのPC内のファイルを直接アップロードすることはできません（初期版の制限です）。

操作手順

01

Step 1 / 3

Instagram接続

画面上部の Instagramに接続 を押してください。既定のブラウザが開き、Metaのログイン・認可画面が表示されます。内容を確認して許可すると、自動でIGUPの画面に戻ります。

接続が完了すると通知欄に「Instagramと接続しました。」と表示され、トークンの有効期限も画面に表示されます。接続済みの状態では、ボタンの表示は 再接続する に変わります。

確認中 起動直後
未接続 接続が必要
接続済み 利用可能

セキュリティについて

アクセストークンはOS標準の暗号化機能を使い、このPC内だけに保存されます。認証サーバーは認証結果を最大5分だけ一時的に保持し、一度使うと無効になります。

02

Step 2 / 3

アカウント確認

アカウント情報を取得 を押すと、接続したプロアカウントのユーザー名・アカウント種別・投稿数が表示されます。

手順1が未完了のまま実行すると「先にInstagramへ接続してください。」と表示されます。先に接続を済ませてください。

03

Step 3 / 3

画像をテスト投稿

「公開画像URL」と「キャプション」を入力し、投稿する を押してください。

画面イメージ

公開画像URL
https://example.com/image.jpg
キャプション
0 / 2,200

画像URLはInstagram側から直接取得できる公開HTTPSのものを指定します。キャプションは最大2,200文字まで、入力中は文字数がリアルタイムで表示されます。

投稿が成功すると、通知欄に「投稿しました（メディアID: …）」と表示されます。

困ったときは

先にInstagramへ接続してください。

手順1（Instagram接続）が完了していません。画面上部から接続を行ってください。

認証処理はすでに進行中です。

Instagramに接続 を連続で押すと表示されます。開いたブラウザでの認証を先に完了するか、ブラウザのタブを閉じてからやり直してください。

認証状態が一致しません。／認証結果が無効か、すでに使用されています。

認証のやり直しが必要です。一度使った認証結果は再利用できないため、IGUPで改めて Instagramに接続 を押してください。

認証情報が無効か期限切れです。（ブラウザ側に表示）

認証の開始から時間が空きすぎた場合に表示されます。IGUPから改めて接続をやり直してください。

この端末では安全な認証情報保存を利用できません。

お使いのPCでOS標準の暗号化機能が利用できない状態です。OSのセキュリティ設定をご確認ください。

投稿内容が不正です。

画像URLまたはキャプションが未入力か、形式が正しくない可能性があります。入力内容をご確認ください。

投稿時にエラーになる

指定した画像URLがHTTPSで公開アクセス可能か、Instagram側から取得できる状態かをご確認ください。
