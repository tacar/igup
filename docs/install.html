IGUP Install Guide

インストールガイド

ダウンロードから初回接続までの手順。IGUPはコード署名のないインストーラーで配布しています。OSの警告をひとつずつ解除して進めてください。

macOS 11+Windows 10 / 11 64bitバージョン 0.1.0

はじめに:なぜ警告が出るのか

IGUP は Apple や Windows の有料開発者証明書を使っていません。そのため初回起動時に「不明な開発元」の警告が表示されます。

これは「危険だから止められた」わけではなく、証明書で署名されていないアプリです、本当に開きますか? というOSの確認です。手順どおりに進めば起動できます(2回目以降は警告なしで開きます)。

Safety

IGUP はあなたのPCの中だけで動くアプリです。取得したアクセストークンはOSの暗号化領域(macOSはキーチェーン、WindowsはDPAPI)に保存され、設定ファイルの書き出しには含まれません。投稿データもすべてPC内に保存されます。

macOS にインストール

1

DMG を開いてアプリを追加

ダウンロードした IGUP-...-dmg を開き、IGUP を Applications フォルダへドラッグします。

2

初回は「右クリック → 開く」

Launchpad からではなく、Finder のアプリケーションで IGUP を右クリックして「開く」を選びます。確認ダイアログが出たらもう一度「開く」を押します。

※ダブルクリックで「開けませんでした」と出た場合は、システム設定 > プライバシーとセキュリティ を開くと「IGUPは使用がブロックされました」という項目があるので このまま開く を押します。

3

それでも開かないとき(ターミナル)

「壊れているため開けません」と表示される場合は、ターミナルで次のコマンドを実行してください。ダウンロード時の隔離フラグを外します。

xattr -dr com.apple.quarantine /Applications/IGUP.app

Windows にインストール

1

セットアップ exe を実行

ダウンロードした IGUP Setup ...exe をダブルクリックします。

2

SmartScreen の「詳細情報 → 実行」

WindowsによってPCが保護されました という青い画面が出たら、「詳細情報」をクリックすると「実行」ボタンが現れます。押して進みます。

3

インストール先を選んで完了

「自分用にインストール」でそのまま進めます。インストール先は変更できます。完了するとスタートメニューに IGUP が追加されます。

初回起動:接続まで

1

ブローカーURLを入力

設定 > ブローカー接続 に、購入時に案内されたサーバーURL(https://...)を入力し、「接続テスト」で 接続OK と出ることを確認します。

2

Instagram に接続

接続 画面の「Instagramと接続」を押すとブラウザが開くので、自分のInstagramアカウントでログインして認証を許可します。IGUPに自動的に戻ります。

3

自動運転をオン

ダッシュボードの 自動運転を有効にする を押せば準備完了。コメントやDMへの自動返信、予約投稿が動き始めます。PCの電源が入っている間だけ動作します。

Note

Instagram自動化にはビジネス/クリエイターのプロアカウントが必要です。個人アカウントのままの場合は、Instagramの設定で種類を切り替えてから接続してください。

よくある質問

Q. アンインストールはどうする?

macOS は Applications から IGUP を削除、Windows は「設定 > アプリ」からアンインストール。設定や投稿データも消して完全に削除したい場合は、それぞれ ~/Library/Application Support/IGUP(macOS)、%APPDATA%\IGUP(Windows)のフォルダも削除してください。

Q. アップデートは?

新しいバージョンのインストーラーを同じ手順で実行すると上書きされます。投稿データや設定はそのまま引き継がれます。

Q. 企業のPCに入れても大丈夫?

ネットワーク的には https:// でブローカーと Meta に接続するだけです。ただし社用PCで未署名アプリのインストールが制限されている場合は、管理者に確認してください。

Q. PCを閉じていても投稿される?

いいえ。IGUPはPC内で動くアプリなので、PCがスリープや電源オフの間は投稿も自動返信も止まります。再起動時に猶予期間内の予約は自動で投稿されます。
